# Axiom Verge 2 한국어 번역 위키 & 윤색 에디터

본 도구는 *Axiom Verge 2* 한국어 패치 제작 과정에서 **고유 고유명사 사전(Glossary)**을 편리하게 열람하고, 인게임 번역 데이터(`Dialogue.csv`, `Notes.csv`, `Hacks.csv`, `Items.csv`, `Skills.csv`)를 문맥(Context)에 맞춰 세련되게 다듬을 수 있도록 설계된 웹 기반 통합 윤색 편집기(SPA)입니다.

이 툴은 추가적인 서버(Node.js, Python 등) 설치 없이, 브라우저와 로컬 데이터베이스 파일만으로 완벽하게 독립 실행됩니다.

---

## 📂 폴더 구조 및 구성 요소

* **`index.html`**: 번역 위키 및 윤색 에디터 프로그램의 본체입니다. 브라우저로 직접 실행합니다.
* **`build.ps1`**: 프로젝트 공용 번역 폴더(`resources/Translations/`)와 마크다운 지침서를 직접 읽어 `wiki_data.js` 데이터베이스를 컴파일하는 PowerShell 스크립트입니다.
* **`wiki_data.js`**: 스크립트 빌드 결과물로, 툴에 필요한 모든 데이터(용어, 대사, 아이템, 기술 등)가 담긴 가볍고 유연한 통합 데이터베이스 파일입니다.
* **`Axiom Verge 2 한국어 용어집 사전 조사.md`**: 고유명사, 지명 등의 지침이 정의된 마크다운 문서입니다.
* **`terms/`**: 자동 추출된 용어들이 가독성 좋은 개별 마크다운 문서(`*.md`)로 분류·보관되는 보관소입니다. (Obsidian 볼트 연동용)

---

## ⚙️ 실행 방법 및 설정

### 1단계. 데이터베이스 빌드 (최초 실행 및 번역 원본 파일 변경 시 수행)
프로젝트 공용 번역 자료(마크다운, CSV)를 툴이 읽을 수 있는 형태로 파싱하여 데이터베이스를 생성하는 단계입니다.
1. **PowerShell** 콘솔을 실행합니다.
2. 프로젝트 내 `wiki` 폴더로 이동하거나 리포지토리 루트 폴더에서 아래 명령을 실행합니다:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\wiki\build.ps1
   ```
3. 빌드가 완료되면 `wiki` 폴더 안에 `wiki_data.js` 파일이 생성되거나 최신 정보로 갱신됩니다.

### 2단계. 웹 에디터 실행
1. 웹 브라우저(Chrome, Edge, Firefox 등)를 실행합니다.
2. `wiki/index.html` 파일을 더블클릭하거나 브라우저 창 위로 드래그 앤 드롭하여 엽니다.

## 🪐 핵심 기능 사용법

### 1. 용어집 사전 (Glossary)
* **카테고리 필터링**: 지명, 종족/사회, 암스 (Arms), 유물/도구, 인물/기록 등 짧은 키워드로 고유명사를 한눈에 분류하여 찾아볼 수 있습니다.
* **실시간 검색**: 상단 실시간 검색창을 통해 영어 용어 또는 한국어 용어 입력 시 실시간 매칭이 이루어집니다.
* **용어 상세 카드**: 상세 학술적 해설과 어원, 그리고 해당 용어가 사용되는 핵심 맥락이 글래스모피즘(Glassmorphism) 스타일 카드로 깔끔하게 표시됩니다.

### 2. 아이템 / 기록물 에디터 (Hacks, Items, Skills, Notes)
* **대상 파일 선택**: 사이드바 필터 영역의 드롭다운을 통해 `Notes.csv`, `Items.csv`, `Skills.csv`, `Hacks.csv` 중 원하는 번역 대상을 자유롭게 전환할 수 있습니다.
* **윤색 작업**: 각 항목의 영어 원문(용어 하이라이트 제공)과 한국어 가번역을 보며, 한국어 번역 윤색안을 입력할 수 있습니다.
* **CSV 내보내기**: 작업 완료 후 우측 상단의 `[파일명] 내보내기` 버튼을 클릭하여, 수정된 한국어 번역이 9번째 열(`Japanese`)에 반영된 패치 파일을 즉시 다운로드할 수 있습니다. 다운로드한 파일은 프로젝트의 `resources/Translations/` 폴더에 덮어씌우면 패처에 바로 반영됩니다.

### 3. 대사 윤색기 (Dialogue.csv)
* **대화 씬(Scene) 자동 그룹핑**: 분절되어 있는 대사들을 파일 내 키 접두사(예: `DLG_INTROFLIGHT`)를 기준으로 묶어 **씬 카드** 형태로 연속 렌더링합니다. 시간 흐름에 맞춰 대화 문맥을 이해하기 편리합니다.
* **씬 통합 컨텍스트 메모**: 각 대화 씬 전체의 배경 상황(예: "인드라가 헬기 안에서 경계하는 중, 딱딱한 반말조")을 카드 상단에 한 줄 메모로 남길 수 있어 작업 일관성을 유지해 줍니다.
* **용어 자동 호버 하이라이트**: 영어 대사 원문 안에 용어집에 등재된 단어가 있으면 밑줄 표시가 되며, **마우스를 올리면 팝업 툴팁**으로 한국어 번역명과 상세 어원이 표시됩니다.
* **Dialogue.csv 내보내기**: 대사 탭 상태에서 우측 상단의 `Dialogue.csv 내보내기` 버튼을 클릭하여 다운로드한 뒤, 프로젝트의 `resources/Translations/` 폴더에 덮어씌워 패처에 반영합니다.

## 💾 중요 안내 및 백업

* **실시간 자동 저장**: 에디터에 타이핑하는 모든 텍스트는 브라우저의 로컬 스토리지(`localStorage`)에 **실시간 자동 저장**되므로, 새로고침하거나 창을 꺼도 이전 작업물이 날아가지 않습니다.
* **초기화**: 우측 상단의 `초기화` 버튼을 클릭하면 모든 변경 사항(로컬 브라우저에 저장된 임시 작업물)이 초기 상태로 완전히 지워집니다. (주의 요망)
* **Excel 호환 및 인코딩**: 내보내기된 CSV 파일은 Excel 등에서 깨짐 없이 바로 열 수 있도록 **UTF-8 with BOM** 방식으로 다운로드 처리됩니다.
